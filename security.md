# Repository Security Statement

## Intended Users
This repository is intended for me, my instructor, and authorized course staff for CSE 3000 coursework. It contains Python code, Jupyter notebooks, and course-provided datasets used for class assignments.

## Risk Assessment
The repository does not contain passwords, API keys, personal information, or confidential university data. The main security risks would be accidentally committing sensitive information in the future or unauthorized changes to assignment code and results.

## Security Measures
I use a `.gitignore` file to help prevent unnecessary local or sensitive files from being committed. Because this is an individual course repository with limited access and no production deployment, additional pull-request rulesets are not necessary at this time. I will not commit credentials, access tokens, or private data to the repository.
